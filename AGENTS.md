# Skill designdocs

Esta carpeta es una skill: instrucciones, plantillas y scripts para crear informes y presentaciones en HTML, con una marca propia cuando corresponde (incluye un kit de ejemplo).

**Si eres un agente:** lee `SKILL.md` antes de crear cualquier informe, reporte, presentación, deck o lámina, y síguelo. `SKILL.md` indica qué archivo de `references/` leer en cada caso; `references/entorno.md` dice cómo abrir, guardar y recibir comentarios.

- Las rutas son relativas a esta carpeta. Si trabajas en otra, antepón la ruta completa de esta carpeta y usa comillas si tiene espacios.
- Revisa qué hay disponible con `node scripts/doctor.mjs`. Si falta algo, sigue con lo que haya y dilo en la entrega.
- Nunca edites las plantillas de `assets/`: cópialas a la carpeta de trabajo.

**Instalar en otros agentes:**

| Agente | Dónde va la carpeta `designdocs` |
|---|---|
| Codex | `~/.agents/skills/designdocs` |
| Claude Code | `~/.claude/skills/designdocs` |
| Otro | Donde lea sus skills. Si no lee skills, indícale que lea `SKILL.md` de esta carpeta |
